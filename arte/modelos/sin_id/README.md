# Low-poly suave sin id

Personas, animales y armas al estilo de PS2 (`tools/modelos/modelos.py bajar <id parecido> --suave`), desde las
hojas de tres vistas que generó el usuario con Canva, que no tienen todavía un id propio en
`assets/inventario.tsv`. Los que lo tienen están en `assets/models/` (los quietos) o en
`arte/modelos/para_riggear/` (los que se animan). Cada uno lleva el presupuesto del id parecido con el que se
convirtió: las mujeres y los hombres, el de `personaje.base.cuerpo_comun`; la vaca, el del buey; el oso polar, el
del oso.
