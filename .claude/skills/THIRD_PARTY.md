# Skills de terceros

Selección hecha para este proyecto (C11 + raylib, Windows y Android): solo skills de
programación de juegos, C/C++, pruebas, depuración, revisión y diseño de juego, y solo con
licencia compatible (MIT o Apache-2.0). Copiadas sin cambios; las licencias están en
`_licenses/`. Cómo se usan aquí: [estepa/SKILL.md](estepa/SKILL.md).
